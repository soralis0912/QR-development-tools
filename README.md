# QR Dev Tools

開発者向けの QR コード生成・解析 Web アプリです。すべての処理はブラウザ内で完結します。

## 生成

- 誤り訂正レベル (L/M/Q/H)、バージョン (1–40 / 自動)、マスク (0–7 / 自動 / なし) を個別に指定
- 各マスクのペナルティ (N1–N4) 一覧。クリックでマスクを切り替え
- セグメント手動指定: 数字 / 英数字 / バイト (UTF-8, Shift_JIS, ISO-8859-1, 16進) / 漢字 / ECI、文字数指示子の上書き
- 終端パターン長、埋め草 (標準 EC 11 / 00 / カスタム)、**終端後に任意データを埋め込み**
- 上級: データコード語の直接指定、形式情報の上書き、コード語の破損、モジュール反転 (クリック / ランダム)
- オーバーレイ表示: 機能パターン / ビット列領域 / RS ブロック / マスク
- ビット列・コード語 (ブロック毎のデータ/EC、インターリーブ後) の表示
- PNG / SVG 保存、クリップボードへのコピー

## 読み取り・解析

- 画像ファイル / ドラッグ&ドロップ / 貼り付け / カメラ / モジュール配列のテキスト入力
- バージョン・EC レベル・マスク・形式情報 (両コピーとハミング距離)・型番情報
- RS ブロック毎の訂正数、訂正されたモジュールをハイライト
- セグメント毎のモード・ビット範囲・文字数・内容・文字コード
- **終端パターン以降の解析**: 埋め草が標準 (EC 11 交互) かを判定し、不一致区間を HEX / ASCII / テキストで表示。さらに終端後をセグメントとして解釈した結果も表示
- **NUL (0x00) 以降にデータがあるか**を検出 (C 文字列として扱うリーダーで切り捨てられるデータ)
- 鏡像シンボルの読み取り

画像からの位置検出とサンプリングには [ZXing](https://github.com/zxing-js/library) の検出器を使い、デコード自体は独自実装で詳細な診断情報を出しています。

## 開発

```sh
npm ci
npm run dev     # 開発サーバー
npm test        # テスト (jsQR / node-qrcode と突き合わせ)
npm run build   # dist/ に出力
```

## デプロイ

> **注意:** ワークフローファイルは権限の都合で `docs/deploy.yml` に置いてあります。
> `.github/workflows/deploy.yml` に移動（GitHub の Web UI で作成して内容を貼り付けても可）してください。

`main` への push で GitHub Actions がテスト・ビルドし、GitHub Pages にデプロイします。
初回はリポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。
